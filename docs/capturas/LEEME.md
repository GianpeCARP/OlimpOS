# Capturas del README

Acá van las imágenes que el README muestra arriba de todo. Están aparte porque
las saca el dueño desde el sistema andando, no se generan con el código.

Con dejar los archivos en esta carpeta alcanza: la sección del README se arma
después con estos nombres.

| Archivo | Qué mostrar | Por qué |
|---|---|---|
| `dashboard.png` | Dashboard del dueño, con el gráfico de ingresos | Es la que explica de qué se trata el sistema en un vistazo |
| `socio-rutina.png` | "Mi rutina" o "Mi cuota", **desde el celular** | El portal del socio se usa en el teléfono, parado en el gimnasio |
| `contador-reps.png` | El contador de repeticiones contando una serie | Es lo más llamativo del proyecto |
| `escritorio.png` | La app de escritorio (Recepción o Cobros) | Deja claro que son dos apps del mismo producto |
| `actividades.png` | Actividades con el horario semanal (opcional) | Muestra la parte de turnos, que no se ve en las otras |

Recomendaciones: PNG, el ancho tal cual sale (no hace falta achicarlas) y **sin
datos reales de personas** — nombres, DNI, teléfonos o mails que existan de
verdad. Si hay que mostrar una ficha, que sea de una cargada para la captura.
