## 1.3 — Tabla Actividad (catálogo)

```sql
CREATE TABLE "Actividad" (
  "id_actividad" INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  "nombre" varchar(80) UNIQUE NOT NULL,
  "descripcion" text,
  "cupo_default" int NOT NULL,
  "precio_clase_suelta" decimal(10,2) NOT NULL,
  "horas_anticipacion_cancelacion" int NOT NULL DEFAULT 0,
  "activo" boolean DEFAULT true
);
```

- `horas_anticipacion_cancelacion`: con cuánta anticipación se puede cancelar
  sin perder la clase. 0 = no se puede cancelar nunca. Lo define el gimnasio
  por actividad.
- Musculación es una fila más en esta tabla.

### REGLA 1 — Cobertura (validar al comprar)

```typescript
// Al comprar un plan de actividad:
function validarCobertura(fechaInicio: Date, membresia: Membresia): void {
  const fechaVencActividad = addMonths(fechaInicio, 1);
  if (membresia.fecha_vencimiento) {
    const vencMembresia = new Date(membresia.fecha_vencimiento);
    if (fechaVencActividad > vencMembresia) {
      throw new ActividadError(400,
        `Tu membresía vence el ${formatFecha(vencMembresia)}. Este plan se ` +
        `extendería hasta ${formatFecha(fechaVencActividad)}. Renová la ` +
        `membresía primero.`);
    }
  }
  // si membresia.fecha_vencimiento es null (sin vencimiento) → cubre siempre, OK
}
```

Hace IMPOSIBLE tener una actividad viva con membresía vencida. Se previene en la
compra, no se maneja después.

### REGLA 2 — Consumo semanal (planes POR_SEMANA)

NO usar contador guardado ni reset. Contar dinámicamente:

```typescript
function puedeReservarSemanal(idSocio: number, idActividad: number,
                              plan: PlanActividad): boolean {
  const [lunes, domingo] = semanaCalendarioActual(); // lunes 00:00 a domingo 23:59
  const reservasEstaSemana = reservasMock.filter(r =>
    r.id_socio === idSocio &&
    turnoDeReserva(r).id_actividad === idActividad &&
    dentroDe(r.fecha_reserva, lunes, domingo) &&
    (r.estado === 'RESERVADA' || r.estado === 'ASISTIO')
  ).length;
  return reservasEstaSemana < plan.cantidad;
}
```

- Semana calendario = lunes a domingo. Se resetea sola porque la ventana se mueve.
- Clases no usadas en la semana SE PIERDEN. No acumulan.

### REGLA 4 — Cancelación

```typescript
function cancelarReserva(reserva: Reserva, turno: Turno, actividad: Actividad): void {
  const horasHastaTurno = horasEntre(ahora(), fechaHoraTurno(turno));
  if (horasHastaTurno >= actividad.horas_anticipacion_cancelacion) {
    // devolver la clase
    if (esPlanPorMes(reserva)) {
      inscripcionDe(reserva).clases_restantes! += 1;
    }
    // POR_SEMANA: la reserva cancelada deja de contar para el tope (se logra
    // filtrando por estado != CANCELADA_* en la regla 2)
    reserva.estado = 'CANCELADA_SOCIO';
    // el cupo del turno se libera solo al bajar el conteo de RESERVADA
  } else {
    // cancela tarde: pierde la clase igual, no se devuelve
    reserva.estado = 'CANCELADA_SOCIO';
    // NO se incrementa clases_restantes
  }
}
```

### REGLA 7 — Upgrade sin descuento

```typescript
function comprarPlan(idSocio: number, nuevoPlan: PlanActividad, membresia: Membresia) {
  validarCobertura(hoy(), membresia);      // regla 1
  verificarSinDeuda(idSocio);              // regla 8
  // si ya tiene un plan activo de la misma actividad, se cierra:
  const planViejo = inscripcionActivaDe(idSocio, nuevoPlan.id_actividad);
  if (planViejo) planViejo.estado = 'CANCELADA';  // SIN crédito ni descuento
  // paga el nuevo completo:
  crearPago(idSocio, nuevoPlan.precio);
  return crearInscripcion(idSocio, nuevoPlan, membresia);
}
```

### REGLA 8 — Deudas

```typescript
function verificarSinDeuda(idSocio: number): void {
  const tieneDeuda = deudasMock.some(d =>
    d.id_socio === idSocio && d.estado === 'PENDIENTE');
  if (tieneDeuda) {
    throw new ActividadError(403,
      'Tenés una deuda pendiente. Regularizala antes de comprar.');
  }
}
```

- Bloquea COMPRAR: renovar membresía, comprar actividad, clase suelta.
- NO bloquea USAR lo ya pagado: reservar con inscripción vigente funciona.
- EXCEPCIÓN CRÍTICA: pagar la deuda SIEMPRE permitido. La función que paga
  deudas NUNCA llama a verificarSinDeuda. No omitir esto o el sistema se traba.
